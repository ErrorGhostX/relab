# Relab Project Context (Antigravity Memory)

Этот файл является «банком памяти» проекта Relab. Он был создан при переносе проекта из `A:\Studying\RINH_3_KURS\Apps\Relab` в `a:\DEV\Lioket\Relab`.

## 🏗️ Архитектура и Принципы

- **Offline-First**: Приложение работает в первую очередь с локальной БД (Room). Все данные в UI — из локальной базы.
- **SyncManager**: Синхронизация с сервером происходит в фоне. Приоритет — локальные изменения.
- **Android Stack**: Kotlin, MVVM, ViewBinding, Navigation Component, Retrofit 2, Room.
- **Backend Stack**: Django 5.2, DRF, MySQL, Channels (WebSocket).

## 📍 Текущий статус (Май 2026)

## ⚠️ Критически важные правила

1. **RetrofitClient.kt**: НИКОГДА не менять `BASE_URL` без согласования.
2. **Язык**: Комментарии в коде — **ТОЛЬКО НА РУССКОМ**.
3. **Data Access**: Всегда через `OrderRepository`, никогда не напрямую через DAO в фрагментах.
4. **Android SDK**: Compile/Target SDK 35.
