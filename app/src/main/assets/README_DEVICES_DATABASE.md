# База данных устройств

## Описание
Файл `devices_database.json` содержит базу данных популярных устройств для автодополнения в форме создания заказа.

## Структура данных

```json
{
  "manufacturers": ["Apple", "Samsung", ...],
  "deviceTypes": ["Смартфон", "Планшет", ...],
  "devices": [
    {
      "manufacturer": "Apple",
      "deviceType": "Смартфон",
      "models": ["iPhone 15 Pro", "iPhone 15", ...]
    }
  ]
}
```

## Как добавить новые устройства

1. Откройте файл `app/src/main/assets/devices_database.json`
2. Добавьте новые производители в массив `manufacturers`
3. Добавьте новые типы устройств в массив `deviceTypes`
4. Добавьте новые устройства в массив `devices`:
   ```json
   {
     "manufacturer": "Новый производитель",
     "deviceType": "Тип устройства",
     "models": ["Модель 1", "Модель 2", ...]
   }
   ```

## Источники данных

Вы можете расширить базу данных, используя данные из:
- GSMArena.com - каталог мобильных устройств
- Официальных сайтов производителей
- Специализированных каталогов электроники

## Примечания

- База данных загружается при первом использовании и кэшируется в памяти
- Данные из базы объединяются с данными из существующих заказов
- Поиск работает без учета регистра
- Автодополнение фильтрует результаты по мере ввода текста
